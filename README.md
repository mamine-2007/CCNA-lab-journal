# CCNA 200-301 Lab Journal 📡

This repository documents my hands-on practice while preparing for the **Cisco CCNA 200-301** certification, using Cisco Packet Tracer.

Each folder contains a lab exercise with the Packet Tracer file (.pkt), a topology screenshot, and a short explanation of what was configured and why.
